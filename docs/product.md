# 产品指南

[English](product.en.md) · [文档索引](README.md) · [项目 README](../README.md)

**Agentic Complex** 是一款以 Apple Silicon macOS 为主平台（Windows x64 端积极开发中）的实验性桌面角色应用，把角色互动、个人智能体和活动回顾放在同一个应用里。桌面上的角色负责即时互动；主窗口是控制面板，默认打开手表盘风格的**「主页」**（倾斜的立体手表盘：左列是页面键，右侧是工具键；中间圆盘分「待处理」「进行中」两页，可点标签或左右滑动切换；下方是今日任务进度；角色卡显示角色当前在做的事、着装和渲染帧率；右上是时钟、连接状态和提醒横幅），顶部导航栏在**「每日简报」**（`⌘1`）、**「对话」**（`⌘2`）、**「记忆」**（`⌘3`）、**「角色」**、**「MMD」**和**「设置」**（`⌘,`）之间切换，开启开发者模式后导航里还会出现**「诊断」**（原「运行记录」并入其中）；**「管线」**是「记忆」页在开发者模式下的页签；**「定时任务」**没有导航入口，从「每日简报」页进入。主页的「待处理」「进行中」两页和今日任务进度依赖「每日简报」功能开着，关掉后这一整块不可用。本文按 [README](../README.md) 的功能顺序，补充各部分的用法和细节。

> [!CAUTION]
> **实验性质与早期状态提示**
>
> 当前项目仍处于早期开发阶段，仅供开发与学习使用：可能存在渲染异常、Token 消耗异常、部分功能/界面未完全接通或页面排版错乱等情况。建议在 **AI Agent 的帮助下** 结合「诊断」页与日志排查问题，并注意检查模型路由与后台观察开关，避免产生预期外的调用消耗。

## 个人智能体

| 场景 | 操作与结果 |
| --- | --- |
| 随时聊几句 | 用快速输入（`⌃⌥Space`）、按住说话（macOS），或在主窗口的「对话」（`⌘2`）页开始或继续角色会话。 |
| 把一件事交给角色 | 说明目标、约束和期望结果。在「每日简报」（`⌘1`）查看运行状态、待处理问题、审批请求和交付结果；需要排查细节时可到「诊断」页（开发者模式）的「对话轮次」查看原始过程。 |
| 派发编码任务 | 在「每日简报」的任务入口或「主页」快捷入口选择 Claude Code 或 Codex、工作目录和权限模式。「每日简报」会汇集角色任务和编码会话的进度与结果。 |
| 保存提醒和定时任务 | 让角色记下提醒。提醒到期时桌面以气泡显示，卡片一出现就算看到，非重复提醒随即算完成；要延后或改时间，在对话里跟角色说，或在主窗口「每日简报」页的提醒里延后、完成或取消。需要重复运行的任务在「定时任务」页（从「每日简报」页进入）配置，可以按每日、每周或编码会话结束触发。 |

**内核、路由与模型。**「设置 › 内核」列出可用的执行内核：

- 随应用提供的 **Pi**（默认，内置 Node SDK 运行时）。
- 本机安装的 **Codex** 或 **Claude Code**。
- 经 **ACP** 协议接入的本机其他智能体工具（如本机命令、npx 或 uvx 运行的 ACP 智能体）。

本机内核的可执行文件默认由后台自动检测，也可以手动选择；账号来源默认是这些工具自己的登录，其中 Codex 也可以改用 API 凭据。Pi 使用的模型服务在**「设置 › 内核 › 账号」**配置，支持 **Anthropic API**、**DeepSeek**、**Grok / xAI**、**OpenAI API**、**兼容 API**（本机回环地址支持无需密钥）、**其他（Pi 目录）**离线目录中的服务以及 **ChatGPT 订阅**。

开启开发者模式且「设置 › 内核」里的「外部执行内核接入」开着时，「设置 › 内核 › 模型」里会出现「按用途分配执行内核」，可以分别为**对话**、**后台任务**、**主动判断**、**屏幕理解**、**记忆与日志**和**电脑操控**指定独立内核、模型与推理强度。回复语言在**「设置 › 交流 › 语音与播报 › 回复语言」**选择（跟随对话 / 简体中文 / English / 日本語 / 按内核设置）。

角色对话中的人设、语气与表现来自角色包。任务、记忆、工具调用和授权由应用管理，切换内核时这些状态仍由应用保留。接入细节见[角色主会话与可替换内核](architecture/agentd.md#角色内核)。

**费用与 Token 消耗提示。**开启活动观察、每日/每周简报、主动发言或让智能体执行多步后台任务时，都会持续发起前后台模型调用。实验期间建议：
- 在**「诊断」**（开发者模式）定期观察今日调用次数、估算费用与单轮上下文大小；
- 使用 Pi 内核时在「设置 › 内核 › Pi 运行」配置**单次运行费用上限**；开发者模式下且「外部执行内核接入」开着时，还可在「按用途分配执行内核」中为轻量判断（如主动判断、屏幕理解）分配更轻量的模型或低推理强度；
- 暂不使用观察简报或主动搭话时，及时在设置中关闭对应开关。

**记忆。**「记忆」（`⌘3`）页保存用户确认的事实、项目任务记录与带来源的档案条目。你可以添加、确认、修改或删除记忆，也可以在支持的条目中打开来源。角色从活动中自动提炼出的事实会先作为候选，供你检查确认。

## 陪伴与感知

- **活动观察**在「设置 › 感知 › 屏幕感知」里开启（默认关闭）。开启后按设置与权限读取前台应用、窗口和最近活动，可一键暂停 1 小时。
- **名单过滤模式**：「设置 › 感知 › 遮蔽与排除」支持两种过滤方式——**白名单模式（「只读名单里的」，默认）**按应用名、应用 ID（Bundle ID）或网站域名过滤；**排除模式（「名单外都读」）**另可按窗口标题正则排除；无痕窗口始终不读取。
- **简报**根据观察记录总结活动。「每日简报」页显示当天的时间线和日报；每日和每周观察简报在「设置 › 感知」里开启。
- **主动发言**在「设置 › 交流 › 主动交互」里调整：「主动交互」选「仅响应对话」还是「自动触发」，「主动交互频率」决定主动发言和动作的频率，「免打扰时段」打开后可以设几个不主动开口的时段。休息和喝水提醒是角色自带的，在气泡「更多操作」里点「关闭此类」就不再提醒。
- **免打扰**在「每日简报」页的菜单里：「安静」会暂停观察，提醒只出卡片、不出声，后台服务重启后仍保留到结束时间；「会议」用于共享屏幕，提醒照常。各类事件的通知方式在「设置 › 交流 › 通知送达」设置。
- **编码会话**：「读取编码会话」开启时，本机自己的 Claude Code 和 Codex 会话只读观察：显示进度和「在 X 里等确认」，审批仍在对应的 CLI 里做。应用派出的编码会话才会出审批卡和完成通知。
- **主动分享**：`⌃⌥S` 读取选中的文字（没有选中时读剪贴板）并带入快速输入；`⌃⌥L` 让角色识读当前屏幕。
- **浏览器扩展**需单独安装，提供 Chrome 普通窗口的标签页状态；网页正文和选区采集需单独开启。细节见[浏览器扩展说明](guides/browser-extension.md)。

## 桌面与画面

- **桌面浮窗**承载简短回复、到期提醒、审批卡和提问卡，可以直接处理或稍后查看。
- 角色没有窗口边框，可以拖到任意位置。窗口盖住她时，她走到窗口旁边；在右键命令环第一级或菜单栏菜单里取消勾选「自由活动」后，她不移动。
- 前台应用全屏时，她默认隐藏；全屏播放视频或游戏时，她留在屏幕边缘。
- 「录屏时隐藏角色」在 macOS 上默认开启（开始录屏或共享屏幕时隐藏一次，按 `⌃⌥H` 重新显示），在 Windows 上默认关闭，在「设置 › 显示 › 桌面显示」里调整。
- `⌃⌥P` 让所有点击临时穿过角色和浮窗。

## 角色、外观与动作

**「角色」**页用于切换角色包、浏览可用动作与外观，最右的竖栏包含：

- **总览**：角色名册，切换角色、导入角色包。
- **外观**：切换角色外观以及 EFMI 模组自带的部件和颜色开关；页内的「导入」页签导入 EFMI 模组外观。
- **动作**：列出角色包自带动作，可预览并开关各动作。角色渲染器连接且实时预览可用时，显示实时 3D 预览。页内的「编排」页签（角色有动作编排时出现）查看和组合动作编排链，「导入」页签导入 VMD、BVH、glTF、GLB、VRMA、FBX 等外部动作文件（直接拖到桌面角色身上时，只有 VMD 和 ZIP 会作为动作导入）。
- **设定**：调整当前角色的行为、渲染参数与舞台/场景设置。
- **MMD**（有角色渲染器时才在竖栏出现）：跳到「MMD」页，共用的 MMD 舞蹈库，可播放、改名和删除导入的 VMD 与 ZIP 舞蹈（可带背景音乐）。

从菜单栏切换角色或外观失败时，桌面会出一条说明原因的提示。

为角色拍照（透明背景截图）在桌面角色的快捷轮盘里：选「拍照」，在她脚下的条里调光圈、对焦，再按快门。

可渲染的角色包提供模型和相关资源；纯文字角色包（如公开版示例角色 `aide`）也可用于对话。角色的人设与设定随包提供。动作导入的格式和限制见[动作导入](guides/motion-import.md)。

## 语音

- **按住说话（macOS）**：按住右侧 `Option` 键说话，松开后发送；识别语言在「设置 › 交流 › 语音与播报」里选择。录音没能启动时，桌面会出一条说明原因的提示。Windows 端按住说话暂未实现。
- **朗读回复**：接入外部语音合成服务时按角色声线朗读；**未配置外部服务时只显示文字，不朗读**；有一句话没能读出来时（令牌无效、服务不可用或连不上），桌面会出一条说明原因的提示。在「设置 › 服务」里选接法，部署见[语音服务部署](guides/tts-deploy.md)。

## 隐私与数据

- 窗口文字、网页正文、输入的文字、编码会话、截图、键鼠计数和使用麦克风的应用，各有独立的读取或分享开关；外发前可开启敏感内容遮蔽。
- 应用将配置和运行记录保存在本机支持目录（macOS 在 `~/Library/Application Support/local.agenticcomplex.companion/` 与 `AgenticComplex/agentd/`），在「设置 › 数据」可管理已存记录和历史归档时长。
- 启用模型或外部语音服务后，完成请求所需的上下文或台词按相关设置发给配置的服务。

## 窗口操作与权限

电脑操作默认关闭。启用后，受支持的会话可以针对指定的原生应用窗口请求观察控件、读取文字、截图或执行动作；每项能力都可以在任务授权小窗中单独选择，许可可以停止或到期。电脑操作桥目前面向原生应用窗口，Chrome 扩展提供浏览器上下文。细节见[电脑操作说明](architecture/tool-gateway.md#电脑操作)和[工具网关](architecture/tool-gateway.md)。

系统权限在「设置 › 能力 › 系统权限」里查看，都可以在用到对应功能时再授予：

| 权限 | 用途 |
| --- | --- |
| 麦克风与语音识别、输入监控 | 按住说话（macOS） |
| 辅助功能 | 读取窗口文字、操作电脑 |
| 屏幕录制 | 屏幕识读和截图 |
| 自动化 | 跳转到终端里的编码会话 |
| 通知 | 改用 macOS 通知时 |

系统权限控制应用能读到什么，应用内的设置继续控制读取和分享的范围。

## 运行与诊断（早期阶段排障建议）

Electron 外壳管理窗口、托盘和后台进程，主窗口与桌面浮窗是它的网页窗口；系统权限等平台能力由原生 helper（`ac-helper`）提供。Python `agentd` 管理角色会话、任务、记忆与工具调用。Metal 宿主（以及开发中的 Windows `efw.exe`）负责渲染和播放角色动作。外部 TTS 提供语音，角色包提供表现资源。

当遇到渲染异常、功能未接通、内核报错或 Token 消耗异常时，可通过以下入口排查（也建议将诊断信息提供给 AI Agent 协助定位）：

- **开启开发者模式**：「设置 › 关于 › 排障 › 开发者模式」，打开后会显示**「诊断」**页、「记忆」页的**「管线」**页签以及 2× SSAA、渲染尺寸、轮次号等内部细项；同一分组还可重新运行**「首次设置」**向导。
- **「诊断」页**（开发者模式下出现在顶部导航，也可从「主页」右侧工具键进入）：查看子进程状态、连接健康度、今日模型调用与估算费用、最近轮次与失败事件，以及开发部署的来源标注；「对话轮次」「事件线」「日志」页签里是每一次模型运行与工具调用的详细记录。
- **「设置 › 关于 › 排障」**：开发者模式下，后台服务没有运行时在此重启 `agentd`（运行中时到「诊断」页的「重启」菜单）、直接打开 `config.json`；日志目录和一键复制脱敏后的诊断信息（不含对话和记忆内容）不需要开发者模式。恢复默认设置（不改角色内核与凭据）在「设置 › 数据」。

发行时可选择 portable 单包或拆分组件目录，详细说明见[运行架构](architecture/overview.md)与[发行组件](components.md)。
